# Character: Veld Family (parents + child)

**Role:** Villagers (3 characters) | **First appears:** I.2 | **Location:** Well

Exhausted parents — polite but dismissive. Young child (~6–7, younger than Mabel) — thinks Mabel's ideas are interesting; small moment of contrast against every dismissive adult in Act I.

**Build tasks:**

Repeat the following for each of the 3 characters (`veld-parent-1`, `veld-parent-2`, `veld-child`):

1. **Scene Setup**
   - [ ] Create a new `.tscn` file that instances `Scenes/characters/character_base.tscn` as its root
   - [ ] Rename the root node (e.g. `"veld-parent-1"`, `"veld-parent-2"`, `"veld-child"`)
2. **Character Data**
   - [ ] Create `Character_<name>_CharacterData.tres` in `GameData/characterData/`
   - [ ] Reference it via `_characterData` on the root node
   - [ ] Set `PersistentId` to match the root node name
3. **3D Model**
   - [ ] Pick or import a GLB model from `assets/3D/Mini Characters 1/Models/GLB format/`
   - [ ] Add it as a child node of the scene (use a smaller-scale model for the child)
   - [ ] Set `CharacterController3D.VisualRoot` to `NodePath("../<model-node-name>")`
4. **Collision Shape**
   - [ ] Add a `CapsuleShape3D` sub-resource with appropriate `radius` and `height`
   - [ ] Apply it to `CollisionShape3D` with a transform offset (typically `y ≈ 0.35`)
5. **Animation Tree**
   - [ ] Override `AnimationTree.root_node` → `../../<model-node-name>`
   - [ ] Override `AnimationTree.anim_player` → `../../<model-node-name>/AnimationPlayer`
   - [ ] Animations needed: idle, walk
6. **Closeup Camera**
   - [ ] Put 3D model meshes on layer 20
